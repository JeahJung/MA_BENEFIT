# Benefit_ITT_test

Code used to estimate the effect of Medicare Advantage plans' provision of expanded
supplemental benefits on enrollees' acute care utilization, using 2017–2022 CMS Medicare
Advantage encounter and enrollment data from a random 20% sample of enrollees. SAS code
builds the analytic file and defines the difference-in-differences treatment, control,
and event-time structure; Stata code performs baseline matching, staggered
difference-in-differences estimation, and other analysis.

Detailed methods, variable definitions, and full results are reported in the published
manuscript and its appendix (see Citation below).

## Citation
